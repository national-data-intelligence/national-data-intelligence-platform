# Sample material

Generated by `tools/make-sample-media.py`, not downloaded and not invented: the
deck and the walkthrough describe the actual NHDW system, so what a presenter
opens in the console looks like something somebody would really show.

The reference PDFs are the project's own documents and live in the NHDW
repository rather than here — point the seeder at them:

    python3 tools/seed-demo.py --docs ../docs/reference

Regenerate the media with:

    python3 tools/make-sample-media.py      # needs python-pptx, Pillow, ffmpeg
