# Bulk source seed CSVs — not included in the public repository

The per-source CSV extracts here (the demo data `seed-realistic.sh` loads into the
lake) are excluded from the published repo for size. Regenerate them from running
source systems with `bundle/scripts/export-source-seeds.sh`, or supply them
locally, to populate a full demo. See also `../0_external/sources/*/sample-data/`.
