# Owner batch — 2026-09-21

Recorded in full before starting, because the details are the contract, not the
titles.

1. **Veil at 70% transparent**, not 90 — the canvas artwork was too faint at
   ninety. Overlay alpha `.30`.

2. **The Overview tab shows a short templated documentation of the project** —
   not a status readout alone. A real, readable description of what the project
   is.

3. **The project-creation form must accept the information the Overview
   shows.** Creating a project is where that documentation comes from.

4. **General rule, beyond this batch: the creation path and the presentation
   path must not drift.** No presentation component without a data source
   behind it, and nothing collected at creation that nothing displays. Every
   field one collects, the other shows.

5. **A "Notes" tab on every project** — notes as direct text, as an uploaded
   file, or both.

6. **A back button on every sub-page** (the project detail page has none).

7. **Remove the glowing drop shadow from the console board.** It looks wrong on
   the app card. (The sign-in board keeps its own.)

8. **The sidebar's gradient runs diagonally**, bottom-right to top-left,
   lighter black at the bottom-right — and the lightening must **start late**,
   only as it approaches the top-left corner.
