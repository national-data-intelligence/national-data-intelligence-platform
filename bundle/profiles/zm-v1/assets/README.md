# Assets — zm-v1

Deliberately empty of a ministry logo.

`profile.yaml` omits `ministry.logo`, so the dashboards render the platform's
own word-mark instead of a crest. A real Zambian deployment drops the Ministry
of Health's file here and adds `logo: <filename>` to the profile — nothing else
changes.

Shipping Ethiopia's crest under a Zambian profile would be worse than shipping
no crest at all.
